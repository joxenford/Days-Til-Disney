Eight segments — one per milestone in Core/Models/Milestone.swift (100, 50, 30, 14, 7, 3, 1, 0). Filled segments are milestones already passed.

```jsx
<MilestoneStrip daysOut={30} />
```

Never invent thresholds; the strip is always eight segments. Pair with a caption like "3 of 8 milestones reached".
