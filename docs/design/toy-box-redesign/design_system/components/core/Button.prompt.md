Full-width block action; the only button shape in the app besides IconButton.

```jsx
<Button variant="primary">Create your first trip</Button>
<Button variant="secondary">I'll do this later</Button>
```

Sentence case, no icons, no shadow. Stacked pairs use a 12px gap. On a park panel use `onPark` for the affirmative action and `outlineOnPark` for the secondary.
